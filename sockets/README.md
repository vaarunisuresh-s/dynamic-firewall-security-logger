# TCP Socket Programming

## Description
This module implements TCP client-server communication using Python's built-in socket library.

## Files
- `server.py` — Accepts client connections, receives messages, and sends a response.
- `client.py` — Connects to the server, sends a message, and displays the server response.

## Requirements
- Python 3.11 or compatible Python 3 version
- No additional packages required

## How to Run
1. Open Command Prompt in the `sockets` folder.
2. Run `python server.py` in the first terminal.
3. Open a second terminal in the same folder.
4. Run `python client.py`.
5. Enter a message when prompted.

## Testing
Basic TCP communication and repeated client connections were tested successfully on Windows.
